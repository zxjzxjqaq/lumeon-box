LumenBox 显示/工作区诊断工具
============================

用途：容器在笔记本上右侧/下侧被遮住（或闪现）时，用本工具收集对方的
屏幕/DPI/任务栏/工作区/LumenBox 配置/窗口实测位置等信息，定位原因。

使用步骤（发给对方）：
1. 把整个文件夹（或 zip）发过去。
2. 对方双击 Run-Diag.bat（不需要管理员，不改任何设置，只读收集）。
3. 运行完会自动用记事本打开报告，并在桌面生成：
   C:\Users\<用户名>\Desktop\LumenBox-Diag-Report.txt
4. 对方把这份 LumenBox-Diag-Report.txt 原样发回来即可。

建议：在容器右/下被遮住的状态下运行本工具（不要先改窗口位置），
这样报告里的"实测窗口边缘 vs 可视区"才有直接证据。

报告包含：
- Windows 版本 / 显示器逐屏 DPI 与工作区 / SPI_GETWORKAREA
- 任务栏自动隐藏状态、所在边、矩形
- LumenBox 窗口实测矩形、所在屏、窗口 DPI（程序渲染用的值）
- config.json：mode / anchored / 保存的窗口位置尺寸 / 每个盒子项数
- 按程序布局算法推算的窗口尺寸与位置、是否溢出屏幕
- 窗口右/下边缘与所在屏工作区、屏幕边界的差值（被遮住的直接证据）
- 安装的 lumenbox.exe 版本与修改时间
