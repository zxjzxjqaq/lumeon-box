# LumenBox M1 MVP · 实施计划

> **For agentic workers:** 本计划由会话内逐切片执行（每片构建+测试+提交）。相比 M0 计划省略逐行代码，改为精确的模块契约 + 数据格式 + 验收标准；实现即落地到本仓库。
> Spec: `docs/设计文档.md` v0.4 §3.1 P0；前置：M0 门禁已通过（DComp 路线）。

**Goal:** 替代 360桌面助手核心场景——桌面文件一键整理进分类格子（玻璃卡片、贴桌）、拖拽归位、可撤销、托盘常驻。

**架构原则:** 核心层（rules/classifier/journal/organizer）纯 C++、零 UI 依赖、全部单测；UI 层（grid/tray）消费核心层回调；文件移动永不删除、不覆盖、可逆。

## 关键契约（签名锁定，供各切片引用）

```cpp
namespace lb {
enum class Category { Doc, Image, Video, Audio, Archive, Installer, Other, None };
std::wstring CategoryName(Category);            // 文档/图片/.../其他
Category Classify(std::wstring_view ext);       // 小写不带点; ".lnk/目录" 由调用方排除
Category ClassifyFile(const std::wstring& path);// 取扩展名并小写后走 Classify

struct MoveRecord { std::wstring src, dst; };
class Journal {                                  // <Desktop>\..\..\%APPDATA%\LumenBox\journal.jsonl
 public: explicit Journal(std::wstring path);
  void BeginBatch();                             // 写 {"type":"batch","ts":...}
  void LogMove(const MoveRecord&);
  std::vector<std::vector<MoveRecord>> Batches() const;   // 按批次分组
  bool UndoLast(const std::function<void(const MoveRecord&)>& onMove); // 逆序回放并删除该批
};

class Organizer {                                // 数据目录: <Desktop>\LumenBox\<分类名>\
 public: explicit Organizer(std::wstring desktopDir, Journal jr);
  struct Summary { int moved; std::map<std::wstring,int> byCategory; };
  Summary OrganizeAll(const std::vector<std::wstring>& extraSkip);   // 一键整理
  bool MoveToCategory(const std::wstring& path, Category c);          // 拖拽归位
  std::vector<MoveRecord> FilesIn(Category c) const;                  // 格子内容 = 目录列举
};
}
```

**整理规则（P0 冻结）:** 只移动文件不移动目录；`.lnk`、隐藏/系统文件、`LumenBox` 目录本身跳过；目标重名自动 `(2)`；移动 = `MoveFileExW(MOVEFILE_COPY_ALLOWED)`；删除永不发生。默认规则表见 `docs/设计文档.md` §6.4。

**格子 UI（P0 冻结）:** 7 格固定类目；每格 = 独立 DComp 视觉（头栏 类名+计数、行 = 图标+文件名，双击打开，右键菜单：打开/打开位置/放回桌面）；格子可点击头栏折叠；网格贴桌（WorkerW，桌面层）；拖文件进格子 = `MoveToCategory`；一键整理后格子以 30ms stagger 浮入。窗口锚定主屏右下（任务栏上方 24px），位置与折叠态持久化于 `config.json`。

**托盘:** 左键/双击 = 显示隐藏格子层；右键菜单 = 一键整理 / 撤销上次整理 / 显示隐藏 / 开机自启(勾选) / 退出。

## 风险与裁剪（写死）

- 多显示器/跨盘移动/双击隐藏图标/快速搜索 = M2，不在本计划。
- 格子内容上限 12 行 + 「+N」提示；无滚动。
- 图标先内存缓存；磁盘图标缓存（§5.1 indexer 磁盘层）推迟到出现性能证据再做。
