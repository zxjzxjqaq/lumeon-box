# M5 实施计划：剪贴板历史

> 日期 2026-09-10 · 依据《剪贴板历史-设计文档.md》v1.0（D7–D10 已按推荐拍板）
> 原则：每阶段以「构建通过 + 测试全绿」为完成门；核心层零 UI 依赖可单测；UI 复用 Spotlight 工程模式。

## C1 核心采集 + 存储（本阶段）

1. **`src/core/clipboard_store.{hpp,cpp}`**（纯 C++，可单测）
   - `ClipEntry{ id, ts, type(text|html|image|files), pinned, text(预览/内联全文), textInline, hash, source, imgW, imgH, payloads[] }`；`ClipPayload{ fmt(text|html|png|hdrop), file(blob 文件名，空=内联 text), size }`。
   - `ClipStore(dir)`：`Load()`（index.jsonl 逐行读，损坏行跳过）、`Prepend()`（FNV-1a 哈希去重→移顶；条数/字节双上限淘汰，置顶豁免）、`Remove/Clear(保留置顶)`、`Save()`（tmp+rename 原子快照）、`Items()`、`LoadPayload()`（blob 缺失容错）。
   - 纯函数：`ClipHash`、`ClipTypeFromFormats`（格式优先级 files>image>html>text）、`MakePreview`、`ClipEntryToJson/FromJson`。
   - 互斥锁保护 `items_`（后台落盘线程写 / UI 线程读）。
2. **`src/core/clipboard_monitor.{hpp,cpp}`**（Win32，不进 core_tests）
   - `ClipboardMonitor::Start(dir, store*, notify, uiMsg, opts)`：主线程建 message-only 窗口 + `AddClipboardFormatListener`；`WM_CLIPBOARDUPDATE` → 序列号/自写标志校验 → OpenClipboard 重试 ≤5×10ms → 采集（GlobalLock+memcpy，≤5ms）→ 内部队列交后台线程。
   - 后台线程（CoInitializeEx MTA）：DIB/DIBV5→PNG（`CreateDIBSection` + WIC `CreateBitmapFromHBITMAP` + PNG Encoder，DIBV5 走 alpha）+ 128px 缩略图（WIC Scaler）；blob/thumbs 落盘 → `store.Prepend + Save` → `PostMessageW(notify, uiMsg)`。
   - 护栏（D9）：图片 >8192px 或解码 >32MB 拒收 → `uiMsg+1` 通知主线程托盘一次性气泡；文本 >1MB 截断。
   - 隐私：存在 `Clipboard Viewer Ignore` 注册格式 → 整条跳过。
   - `CopyEntryToClipboard()`：快捷复制回写（text→CF_UNICODETEXT；html→"HTML Format"+纯文本；png→"PNG"+CF_DIB；hdrop→CF_HDROP），全程置自写抑制标志。
3. **`tests/test_clipboard_store.cpp`**：哈希稳定、去重移顶、置顶豁免、条数/字节淘汰、Save/Load 回读、损坏行跳过、blob 缺失容错、类型优先级、预览生成。
4. **`config.{hpp,cpp}`**：新增 `clipboardEnabled(true)/clipboardHotkey("Ctrl+B")/clipboardMaxEntries(100)/clipboardBlobMB(64)/clipboardRecordSource(true)/clipboardPaused(false)`，非法值回默认。
5. **`CMakeLists.txt`**：`lumenbox` 加 3 个新 .cpp；`core_tests` 加 test + clipboard_store.cpp。
6. **完成门**：`cmake --build build --config Release` 通过，`core_tests` 全绿。

## C2 面板 UI

7. **`src/ui/clip_panel.{hpp,cpp}`**：分层窗口 + `UpdateLayeredWindow` + GDI+（同 Spotlight）；头部 40px（类型 Tab + 暂停 + 清空 + ✕）；卡片列表（预览/缩略图 + 时间·来源 + 复制/置顶/删除钮）；滚轮/PGUP·PGDN 滚动；键盘 ↑↓/Enter(复制并关)/Del/Esc/Tab；置顶区置前；缩略图会话内缓存；空状态光尘（失焦即停）。`OnStoreChanged()` 支持打开时实时刷新。

## C3 集成

8. **`main.cpp`**：`RegisterHotKey(id=5, Ctrl+B)`，失败试 `Ctrl+Alt+B`，再失败托盘气泡；`on_key` id==5 → `clipPanel.Toggle()`；`WM_APP+6` → `clipPanel.OnStoreChanged()`；`WM_APP+7` → 拒收气泡；托盘菜单加「剪贴板历史 / 暂停记录 / 清空历史」（id 10/11/12）；退出 `monitor.Stop()`。
9. **完成门**：全量 Release 构建 + `core_tests` 全绿；人工矩阵按设计文档 §8.2 执行（另轮）。

## 风险预案

- DIB→PNG 转码边界（16bpp/BITFIELDS/调色板）：走 `CreateDIBSection` 系统解析，不全手写解码；§8.2 三源交叉验证。
- `UpdateLayeredWindow` 大列表滚动闪烁：整帧原子重绘（Spotlight 已验证该模式无闪烁）。
- 锁竞争：锁内只做内存操作 + 小文件 IO（Save ≤ 数百 KB）。
