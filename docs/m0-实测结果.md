## 重要发现（已并入设计文档 v0.4）

1. **本机缺失 Windows.UI.Composition 组件**：System32 无 `Windows.UI.Composition.dll`、WinRT 激活注册表项被精简，Compositor 激活返回 E_ACCESSDENIED（PowerShell 投影 / 计划任务 / explorer 启动的干净进程均被拒）。→ **动效层切换为原生 DirectComposition（dcomp.dll）**：纯 COM、进程内、所有 Win10/11 自带，动画同样运行在 DWM 合成线程；弹簧感用三次多项式（0→+3% 过冲→回落，420ms）实现。国内精简系统极多，该改动对产品是加固；健康系统上可运行时探测 Composition 并升级原生弹簧（tools/compo_probe 即探测器原型）。
2. **F9 全局热键被本机其他程序占用**（RegisterHotKey 失败）→ spike 改用 Ctrl+Alt+1/2；产品按设计 §5.1 做冲突提示+改键。
3. **修复一处真实崩溃**：WM_SIZE 可能早于图形上下文初始化到达，对未初始化的投影/COM 对象调用方法 → AV（0xC000041D）。教训：图形对象生命周期必须先于一切窗口消息路径；本机 SDK 投影头无 `CreateDesktopWindowTarget` 语法糖，须走 `ICompositorDesktopInterop`（DComp 路线已无此依赖）。
4. PS 5.1 工具脚本须纯 ASCII（无 BOM UTF-8 中文注释会被按 GBK 误读破坏语法）。
