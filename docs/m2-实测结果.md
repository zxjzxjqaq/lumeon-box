## 关键设计决策（与设计文档 v0.6 一致）

1. **`.lnk` 不参与自动归类提示**（与 OrganizeAll 一致，§6.4）。
2. **双击隐藏默认 `hook`**（D6），托盘可切热键模式；钩子安装独立线程，避免 UI 假死影响 shell。
3. **Ctrl+Space 冲突** → 托盘一次性气泡提示（§5.1 P0），不阻塞主流程。
4. 监听只监**桌面顶层**（bWatchSubtree=FALSE），不扫全盘；搜索**一次性**开始菜单/App Paths 索引，无后台扫描。
